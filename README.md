# Movie Explorer

React movie explorer app using OMDb API.

## Features
- View movies
- Search movies
- Filter by type (movie/series)
- View movie details
- Add/remove favorites
- Favorites persisted in `localStorage`

## Routes
- `/`
- `/movie/:id`
- `/favorites`
- `/about`

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Netlify
- Build command: `npm run build`
- Publish directory: `dist`
- SPA redirect included in `public/_redirects`
